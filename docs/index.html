ReVanced Builder

Automated APK patching with Morphe and Morphe-compatible bundles such as Adobo, Piko and community patch repos. Download stock APKs, apply patches, and re-sign them — all from a single config file.

Open Configuration Generator View on GitHub

Features

Everything you need to build patched APKs automatically

⚙️

Configuration Generator

Visual config.toml builder with an app catalog, interactive patch selector, live preview, and one-click download. No manual editing required.

Open Generator →
📦

Multi-Source Patches

Merge several Morphe-compatible bundles in one app. Each patch is applied from the bundle that lists it, and later bundles win on duplicate names. The brosssh external-bundles aggregator is supported too.

⚡

Build Cache

Smart TTL-based caching with SHA-256 integrity verification. Skip re-downloading unchanged files and reduce build times significantly.

📋

Build Reports

Every build writes a build.md listing the patches applied to each app. extras combine-logs merges the reports of separate builds.

🔍

Version Tracking

Remembers the CLI, patches and app versions of the last build, so version-tracker check can tell when a rebuild is needed. Renovate and Dependabot keep the toolchain current.

🚀

Parallel Builds

Build several apps at once. Each stock APK comes from the first source that works: APKMirror, Archive.org, APKPure, GitHub, Aptoide, APKMonk, then Uptodown. Cloudflare-protected APKMirror pages are read through a real browser.

Quick Start

Get up and running in four steps

1

Configure

Use the configuration generator to create your config.toml visually, or edit it by hand.

2

Select Apps

Pick from the app catalog with pre-filled download URLs, patch sources, and recommended settings.

3

Choose Patches

Browse available patches with the visual selector. Search, filter, and toggle patches with a single click.

4

Build

Run uv run python -m scripts.cli build --config config.toml and the system handles downloading, patching, and signing.
